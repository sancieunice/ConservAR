# 3D Models Directory

Place your 3D model files here.

## Supported Formats
- `.glb` (GLTF Binary) - Recommended
- `.gltf` (GLTF Text)
- `.usdz` (iOS AR Quick Look)

## Example Files
- `elephant.glb`
- `tiger.glb`
- `panda.glb`

## File Path Reference
When adding models to your database/storage, reference them as:
```
/model/your-filename.glb
```

For example, if you place `elephant.glb` here, use `/models/elephant.glb` in your code.
